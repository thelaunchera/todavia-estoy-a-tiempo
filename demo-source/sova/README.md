# SOVA Headphones

Original bilingual brand demo. Install with npm install, run npm run dev, build with npm run build.

The 10 original PNG assets and their production prompts are retained in the owner’s private Studio kit. Copy them into public/resources using the filenames referenced by src/site.js before running. Portrait publication remains pending explicit owner authorization. No portrait image or image bytes are included in this public source directory.

The private kit includes the complete offline demo, original photos, prompts, reconstruction guide and verification results.
