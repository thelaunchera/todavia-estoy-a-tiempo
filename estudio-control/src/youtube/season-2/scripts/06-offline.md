# SEASON 02 · E06 — OFFLINE
**Series:** OFF BRIEF — THE CREATIVE HOUSE
**Setting:** Studio editing desks, offline production table, exterior hallway
**Featured cast:** NOVA, JULES, IMANI, SAGE, NIA, RUBY, MATEO
**Target length:** 6–8 minutes with visual loading-button gags
**Status:** Full dialogue draft v1 · eight scenes · production not started

### SCENE 1 — COLD OPEN: LOADING
**SHOT:** Extreme close-up of a spinning loading symbol on Nova's monitor. It keeps spinning. The shot holds an uncomfortably long time.
**ACTION:** Slow dolly back reveals Nova staring at the screen, motionless. Wider still: the whole studio is staring at different screens.
NOVA: The internet is down.
RUBY: Like... all of it?
JULES: Just our building.
MATEO: A local apocalypse. How boutique.
IMANI: Does anyone still know how to use paper?
**ACTION:** All look at Nia holding a freshly printed folder.
NIA: I have been preparing for this my entire life.
**CUT:** OFF BRIEF title, with a dial-up-style original comic squeal.

### SCENE 2 — THE NON-DIGITAL MORNING
**SHOT:** Earlier. A tidy studio set; Nova uploads a video proof, Jules enters with an event schedule.
JULES: We have six hours until the rehearsal approval.
NOVA: Cut's exporting. Backup's on the external drive.
IMANI: Great. Did you make a local copy of today's shot list?
JULES: It's in the cloud.
NIA: Which one?
JULES: All the clouds.
SAGE: My latest color palette is on the shared board.
RUBY: Is this an intervention for cloud computing?
MATEO: I put the tagline in a document called final-final-really-final.
NOVA: That's not a versioning system. That's a cry for help.
**SFX:** All notifications drop out simultaneously.
JULES: Huh. Weird.
NOVA: Don't say weird.
RUBY: We're all thinking weird.

### SCENE 3 — FIRST PANIC
**SHOT:** Multiple screens show abstract offline icons; a cheerful progress bar is frozen at 99%.
NOVA: The upload stopped at ninety-nine percent.
MATEO: An artistic choice.
JULES: We need the venue floor plan and catering list.
SAGE: I need the color references.
IMANI: I need the latest budget.
RUBY: I need a nap.
NIA: Nobody panic.
**ACTION:** The same line triggers a collective look toward the ceiling.
NIA: Fine. Limited panic. In alphabetical order.
NOVA: Can I go first? I have a render that took four hours.
JULES: The client meeting is still happening, right?
IMANI: Yes. A network outage is not a cancellation unless we tell them it is.
RUBY: Could we send a carrier pigeon?
MATEO: Not unless we can expense its tiny blazer.

### SCENE 4 — FIND THE REAL PROBLEM
**SHOT:** Jules stands in hallway holding her phone toward a window while Imani checks the building notice.
JULES: Cellular works outside. The provider has a local outage.
NIA: Good. We stop rebooting everything and work offline.
NOVA: I already have all camera footage on local drives.
SAGE: I saved last week's palette.
RUBY: Is last week's palette illegal?
SAGE: It's emotionally outdated.
IMANI: We need one source of truth that works without Wi-Fi.
NIA: Paper on the table, files on the drive.
JULES: And a phone hotspot only for the one urgent approval.
NOVA: Can everyone stop asking the hotspot to stream videos?
MATEO: My emotional-support playlist is not optional.
NOVA: It is today.

### SCENE 5 — THE OFFLINE WORKFLOW
**SHOT:** A quick energized planning montage: handwritten cards, paper shot list, one external SSD, careful file names.
JULES: Rehearsal: four o'clock. Vendor call: four thirty. That's now written on actual paper.
IMANI: Excellent. Production costs go here. No double purchases.
SAGE: I'm matching reference prints under the same lighting so color doesn't drift.
NOVA: I can cut from the local proxies. I just can't send the review link yet.
RUBY: What if the offline edit has more personality?
NOVA: Does your personality have a file format?
RUBY: Mostly chaos.
MATEO: Save as chaos_v3.
NIA: Please never name a file that.
**ACTION:** Nova calmly renames a folder to clean version numbers. Mateo pretends to faint.
IMANI: Look, an organized creative process. Nature is healing.

### SCENE 6 — A SMALL FAILURE
**SHOT:** Jules hurries back from the hallway holding her mobile phone.
JULES: I used the hotspot to send the event proof.
NOVA: Did you send the new version or the old one?
JULES: The file said FINAL.
NOVA: There are three FINAL files.
MATEO: You can't blame a writer for naming conventions.
NIA: We'll correct it. Nobody send anything else until we check the version.
SAGE: The color on the old one is wrong.
RUBY: How wrong?
SAGE: It looks like a sad banana.
**ACTION:** Nova quickly locates the right export.
NOVA: Here. Correct aspect ratio, captions, color. I checked it.
IMANI: Upload once. Confirm receipt. Record the file name.
JULES: Roger. I'm feeling very analog and very powerful.

### SCENE 7 — THE CONNECTION RETURNS
**SHOT:** The original spinning icon finally resolves. A gentle notification chime.
NOVA: We're back.
RUBY: I missed you, internet.
JULES: The client confirmed the corrected file.
IMANI: We stayed within budget.
SAGE: The color survived.
NIA: We need a repeatable offline plan.
NOVA: Local backups, named versions, export checklist, minimal cloud dependence.
MATEO: And one very tiny printed apology to the router.
RUBY: It had a difficult day.
NIA: Fine. But the router doesn't get a desk.
**ACTION:** The group laughs. Nova saves a final local backup visibly.

### SCENE 8 — TAG: A HUMAN ERROR
**SHOT:** Late evening. Nia prints a simple emergency checklist and tapes it near the desks.
NIA: There. In case the internet goes down again.
JULES: Great. Where's the printer connected?
**ACTION:** The printer flashes "offline" on a tiny screen. It refuses to print another copy.
NOVA: That's not the internet. It's the printer.
RUBY: We're being haunted by technology with boundaries.
MATEO: New season title: "No Devices."
IMANI: No. We would still have all of you.
**END — CUT TO CREDITS.**
