Tu prompt listo para copiar

Actúa como diseñador web y desarrollador experto en experiencias mobile-first. Vamos a crear una web funcional para [NOMBRE DE MI NEGOCIO]. Mi negocio ofrece [SERVICIO O PRODUCTO], ayuda a [PÚBLICO IDEAL] a conseguir [BENEFICIO PRINCIPAL] y se diferencia por [DIFERENCIADOR REAL]. El objetivo de la página es [RESERVAS / SOLICITUDES / CONTACTO / VENTA], con un solo botón de acción principal: [CTA]. Usa mis colores [COLORES], tipografías [TIPOGRAFÍAS] y fotografías originales [ARCHIVOS O ENLACES]. Estructura: navegación sencilla, hero con propuesta clara y CTA, servicios o productos, cómo funciona, sobre nosotros, preguntas frecuentes y contacto. Debe ser rápida, accesible, responsive y fácil de usar en iPhone. Usa únicamente datos que yo proporcione; no inventes precios, reseñas, promesas, estadísticas ni fotografías. Antes de construir, enumera en una lista corta los datos esenciales que faltan. Si los tienes, crea la primera versión funcional y explícame cómo verla, probar botones y solicitar correcciones específicas sin rehacer lo que ya funciona.
Act as an expert web designer and developer focused on mobile-first experiences. Build a functional website for [MY BUSINESS NAME]. My business offers [PRODUCT OR SERVICE], helps [IDEAL AUDIENCE] achieve [MAIN BENEFIT], and stands out because [TRUE DIFFERENTIATOR]. The page goal is [BOOKINGS / INQUIRIES / CONTACT / SALES] with one primary call-to-action: [CTA]. Use my brand colors [COLORS], fonts [FONTS], and original photos [FILES OR LINKS]. Sections: simple navigation, clear hero and CTA, products or services, how it works, about us, FAQs and contact. The website must be fast, accessible, responsive and easy to use on iPhone. Use only information I give you; do not invent prices, reviews, promises, statistics or photographs. Before building, briefly list any essential missing information. Once you have it, create a working first version and explain how to preview it, test buttons and request specific edits without rebuilding parts that already work.
